# android-ai-assistant

Hands-on projects focused on mobile AI, Android engineering, backend integration, and production-minded AI systems.

## Projects

### 1. Mobile AI Assistant
Native Android AI assistant built with Kotlin, Jetpack Compose, ViewModel/StateFlow, Retrofit/OkHttp, FastAPI, and Anthropic Claude.

Includes:
- lifecycle-aware Android state management
- repository-based networking architecture
- secure server-side AI provider integration
- timeout and error handling
- request IDs and latency logging
- Android and backend unit tests
